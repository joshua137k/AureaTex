Your VS Code. Our Engine.

Write locally with your favourite extensions. Hit F6 and we compile in your server, returning the PDF in seconds.

Download the VS Code plugin v0.1.1 · .vsix
  1. In VS Code open Extensions → ··· → Install from VSIX… and pick the downloaded file.
  2. In Settings search AureaTeX and fill in your username, then run AureaTeX: Definir Password from the Command Palette.
  3. Open your LaTeX folder and press F6.

New in v1.1

Bring your own AI.
It works on your project.

AureaTeX speaks the Model Context Protocol. Connect the assistant you already use and let it read your sources, fix errors and recompile — while you watch the edits appear live in the editor.

  • MCP server built in. Read, search, edit and compile from Claude Code, Claude Desktop, Cursor, VS Code, opencode or Antigravity.
  • Copy for AI. One click puts the file tree and your .tex files on the clipboard as Markdown — paste into any chat.
  • You stay in control. Read-only or edit tokens, with expiry dates, revocable at any time. Your files never leave your server unless you ask.
